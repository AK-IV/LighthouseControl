# Lighthouse Control

Android-приложение (Kotlin + Jetpack Compose) для управления питанием базовых станций SteamVR по Bluetooth LE.

- **v1.0 (HTC Vive):** включить / сон. Нужен ID станции (8 символов с наклейки на задней стороне), вводится один раз.
- **v2.0 (Valve Index и др.):** включить / standby / сон, плюс чтение реального состояния.
- Станции, их названия и ID сохраняются.
- Кнопки «Включить все» / «Усыпить все».
- Плитка в шторке «Базовые станции»: одно нажатие включает или усыпляет все станции.

## Как запустить

1. Откройте папку проекта в Android Studio (Ladybug 2024.2 или новее), дождитесь Gradle Sync.
2. Подключите телефон (Android 8.0+) с включённой отладкой по USB и нажмите Run.
3. В приложении нажмите «Добавить», выберите найденную станцию, задайте название (для v1.0 — ещё и ID).
4. Плитку добавьте вручную: шторка → «Изменить» → перетащите «Базовые станции».

## Структура

```
app/src/main/java/app/lighthousecontrol/
├── ble/LighthouseProtocol.kt   — байты команд v1/v2, разбор состояния
├── ble/GattSession.kt          — одно GATT-подключение на корутинах
├── ble/LighthouseBle.kt        — сканирование, очередь (Mutex), повторы при сбоях
├── data/                       — модель Station и хранилище (SharedPreferences)
├── StationController.kt        — общая логика для экрана и плитки
├── work/PowerAllWorker.kt      — «всем станциям» в фоне через WorkManager
├── tile/PowerTileService.kt    — плитка в шторке
└── ui/                         — экраны на Compose
```

## Протокол

| | Характеристика | Включить | Сон | Standby |
|---|---|---|---|---|
| v2.0 | `00001525-1212-efde-1523-785feabcd124` | `01` | `00` | `02` |
| v1.0 | `0000cb01-0000-1000-8000-00805f9b34fb` | `12 00 00 00` + ID(LE) + 12×`00` | `12 02 00 01` + ID(LE) + 12×`00` | — |

ID для v1.0 записывается в обратном порядке байтов: `1A2B3C4D` → `4D 3C 2B 1A`.

## Известные ограничения

- Станция v1.0 не сообщает своё состояние, поэтому у неё показывается последняя отправленная команда (со звёздочкой).
- Плитка переключает «все вкл ↔ все сон» по последней команде, а не по реальному состоянию.
- На Android 11 и ниже для BLE-сканирования нужна включённая геолокация.
